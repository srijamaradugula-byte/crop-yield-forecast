# An Intelligent System to Forecast Per-Acre Yield Ahead of Harvest

**Domain:** Machine Learning & Predictive Analytics
**Keywords:** crop, yield, estimation, gradient, boosting, regression

## Abstract
This work presents a Gradient Boosting regression model to forecast per-acre yield ahead of harvest, addressing the problem of crop yield estimation through a data-driven approach. Data collected from state agriculture department field data is cleaned, transformed, and used to build and evaluate the underlying model. The outcome is delivered as a farmer advisory mobile alert, enabling practical adoption beyond the classroom.

## Project structure
```
src/        config, data cleaning, training, prediction, alert builder
app/        FastAPI service used by the mobile app
data/       yield_data.csv (sample generated; replace with real data)
models/     trained model + metrics (generated by training)
tests/      pytest tests
```

## Quick start
```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python -m src.generate_sample_data   # skip if you have real data in data/yield_data.csv
python -m src.train                  # trains, evaluates (MAE, RMSE, R2), saves model
uvicorn app.api:app --reload         # API docs at http://127.0.0.1:8000/docs
pytest                               # run tests
```

## Example request
```bash
curl -X POST http://127.0.0.1:8000/predict -H "Content-Type: application/json" -d '{
 "district":"Eluru","crop":"paddy","season":"kharif","soil_type":"alluvial",
 "irrigation":"canal","area_acres":3,"rainfall_mm":780,"avg_temp_c":28,
 "humidity_pct":70,"fertilizer_kg_per_acre":120,"sowing_month":7}'
```
The response contains the forecast (quintals/acre) and an English + Telugu advisory alert.

## Method
1. **Cleaning:** normalise text, drop duplicates / missing targets, per-crop 3xIQR outlier filtering.
2. **Transformation:** median imputation + scaling (numeric), mode imputation + one-hot (categorical).
3. **Model:** `GradientBoostingRegressor` tuned with 3-fold GridSearchCV.
4. **Evaluation:** 80/20 split; MAE, RMSE, R2 saved to `models/metrics.json`.
5. **Delivery:** FastAPI endpoint -> mobile app shows the advisory alert.
